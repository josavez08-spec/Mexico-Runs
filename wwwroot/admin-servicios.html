Correo: el flujo de enlace de un solo uso está implementado. Para enviar mensajes configura SMTP_HOST, SMTP_PORT, SMTP_SSL, SMTP_FROM, SMTP_USER y SMTP_PASSWORD en el archivo local .env; luego reinicia el servidor. No compartas ese archivo.

Pagos: los pagos siguen siendo de demostración; esta aplicación aún no se conecta a una pasarela. Para cobrar de verdad hay que integrar una cuenta de proveedor con checkout alojado y confirmar el pago en el servidor. Nunca captures CVV ni guardes números completos de tarjeta.
